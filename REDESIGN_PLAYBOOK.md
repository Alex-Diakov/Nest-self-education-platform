## 🚀 ЧОМУ РЕДИЗАЙН ТЕПЕР ВІДБУВАЄТЬСЯ ШВИДКО І БЕЗ БОЛЮ?
У системі впроваджено **6 рівнів архітектурної ізоляції**:
1. **Токени дизайну (Design Tokens):** кольори, шрифти та скруглення винесені в єдині змінні.
2. **Відокремлення контенту (Content Layer):** жодних текстів, «зашитих» всередині коду.
3. **Медиа-пайплайн (Zero-Broken-Images):** розумні заглушки, захист від стрибків екрана (CLS) та готове ТЗ для фотосесії.
4. **Атомарний UI-Kit:** `M3Button`, `M3Card`, `M3Badge`, `M3Callout`, `M3Divider`, `M3Container`.
5. **Шаблони-контейнери (Layout Archetypes):** `CatalogLayout`, `EditorialArticleLayout`, `InteractiveFlowLayout`, `LandingLayout`.
6. **Інтерактивна лабораторія:** кнопка «Стилі та пресети» у футері сайту для миттєвого тестування.

## 1. ЯК ЗМІНИТИ СТИЛЬ ТА ВІЗУАЛ ВСЬОГО САЙТУ

### А. Швидке тестування наживо:
У підвалі (футері) сайту натисніть кнопку **✨ «Стилі та пресети»**.
Ви зможете в один клік перемикатися між 4 готовими стилями:
* **Editorial Modern (Поточний):** людиноцентрична типографіка (`e-Ukraine`), м'які скруглення (20px), скруглені кнопки.
* **Swiss Architectural:** швейцарський строгий мінімалізм (Inter/Helvetica, 8px картки, 6px кнопки).
* **Literary Journal:** престижний журнал (*The Atlantic* / *New Yorker*) із заголовками-антиквою.
* **Executive Tech Lab:** естетика *Stripe / Linear* із чіткою геометрією та темними акцентами.

### Б. Постійна зміна стилю в коді:
Відкрийте файл:
```
src/design-system/tokens/design-tokens.css
```
Змініть будь-який токен — зміни миттєво застосуються до всіх сторінок:
* `--font-family-primary`: шрифт основного тексту.
* `--font-family-display`: шрифт головних заголовків.
* `--radius-btn`: форма кнопок (`9999px` для плавних, `8px` для сучасних, `2px` для гострих).
* `--radius-card`: скруглення карток (`20px`, `12px` або `4px`).
* `--radius-dialog`: скруглення модальних вікон.

## 2. ЯК РЕДАГУВАТИ ТА ПЕРЕПИСУВАТИ ТЕКСТИ
Контент повністю відділений від верстки. Вам не потрібно шукати текст у HTML або JSX-файлах!

| Що ви хочете змінити | Де лежить файл |
|---|---|
| **Головна сторінка** (Hero, 4 картки телеметрії, 4 стовпи методології, FAQ, фінальний CTA) | `src/content/homeContent.ts` |
| **Про автора та платформу** (біографія, 4 факти, 3 принципи, таймлайн) | `src/content/aboutContent.ts` |
| **Глобальні реквізити бренду** (контакти, Telegram, ініціали, соцмережі) | `src/content/siteConfig.ts` |
| **Статті блогу** (лонгріди, тези, оглавлення) | `src/services/blog/blogService.ts` |
| **Психометричні сканери та тести** (питання, шкали, алгоритми підрахунку) | `src/services/tests/testService.ts` |
| **Програми та послуги** (тарифи, опис сесій) | `src/services/offerings/offeringsService.ts` |

*Усі тексти мають версії для 3 мов: `uk`, `ru`, `en`.*

## 4. ЯК ЗБИРАТИ НОВІ СТОРІНКИ ЗА ДОПОМОГОЮ ШАБЛОНІВ (Layout Archetypes)
Щоб сторінки виглядали узгоджено, використовуйте готові контейнери:
```tsx
import { CatalogLayout, EditorialArticleLayout, InteractiveFlowLayout, LandingLayout } from '../../design-system';
```

### Приклад 1: Сторінка-каталог або вітрина (`CatalogLayout`)
```tsx
<CatalogLayout
  badge="ПРИКЛАДНА ДІАГНОСТИКА"
  title="Оцифруйте свій когнітивний профіль"
  subtitle="Точні психометричні сканери для лідерів"
  filters={<Ваші фільтри />}
>
  <div className="grid grid-cols-1 md:grid-cols-2 gap-6">
    {/* Ваші картки M3Card */}
  </div>
</CatalogLayout>
```

### Приклад 2: Сфокусований тест або квіз (`InteractiveFlowLayout`)
```tsx
<InteractiveFlowLayout maxWidth="reading">
  <TestRunner />
</InteractiveFlowLayout>
```
